Switch + Router 1941

📝 Task 1: ตั้งค่า VTP

! ที่ Switch ตัวแม่ (Server)
Switch(config)# vtp mode server
Switch(config)# vtp domain mydomain

! ที่ Switch ตัวลูก (Client)
Switch(config)# vtp mode client

📝 Task 2: Router-on-a-stick

Router(config)# interface g0/0
Router(config-if)# no shutdown ! เปิดพอร์ตหลักก่อน
Router(config-if)# exit

! สร้างซับอินเทอร์เฟซสำหรับ VLAN 10
Router(config)# interface g0/0.10
Router(config-subif)# encapsulation dot1Q 10 ! ต้องทำก่อนใส่ IP
Router(config-subif)# ip address 192.168.10.1 255.255.255.0

🔵 1. LACP (IEEE Standard)

โหมดที่ใช้คู่กันคือ: active - active หรือ active - passive

Switch(config)# interface range f0/1-2
Switch(config-if-range)# channel-group 1 mode active

Switch(config)# interface port-channel 1
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit

🟢 2. PAgP (Cisco Proprietary)

โหมดที่ใช้คู่กันคือ: desirable - desirable หรือ desirable - auto

Switch(config)# interface range f0/11-12
Switch(config-if-range)# channel-group 2 mode desirable
Switch(config-if-range)# exit

Switch(config)# interface port-channel 2
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit

Lab 13: WLC-PT Config & Server Config

GUI In Packet Tracer

⚠️ ข้อควรระวัง: การตั้งค่า WLC ในโจทย์นี้ ต้องคลิกที่ตัวอุปกรณ์ "WLC-PT" โดยตรง และใช้เมนูภายในแท็บ "Config" เท่านั้น ไม่ต้องผ่าน Web Browser

🖥️ Task 1: การตั้งค่าเครื่อง Server (แท็บ Services)

ให้คลิกที่เครื่อง Server ภายในโปรแกรม PT แล้วเลือกแท็บ Services ด้านบน

1. การตั้งค่าหน้าเว็บ (HTTP)

  • คลิกที่เมนู HTTP ด้านซ้ายมือ
  • ตรวจสอบให้แน่ใจว่าทั้ง HTTP และ HTTPS ถูกเลือกสถานะเป็น On[cite: 7, 8]
  • (สามารถตั้งค่านี้ได้ทั้งเครื่อง SRV1 และ SRV2)[cite: 7, 8]

2. การตั้งค่าการแจก IP (DHCP)

  • คลิกที่เมนู DHCP ด้านซ้ายมือ -> เปลี่ยน Service ให้เป็น On
  • Pool Name: ใส่ชื่อ Pool (เช่น serverPool)
  • Default Gateway: ใส่ IP Gateway ของ VLAN นั้นๆ
  • DNS Server: ใส่ IP ของเครื่อง Server ตัวที่ทำหน้าที่เป็น DNS
  • Start IP Address และ Subnet Mask: ใส่หมายเลข IP เริ่มต้นที่จะแจก
  • กดปุ่ม Save ด้านล่าง

3. การตั้งค่าระบบยืนยันตัวตนสำหรับ Wi-Fi (AAA)

  • คลิกที่เมนู AAA ด้านซ้ายมือ -> เปลี่ยน Service ให้เป็น On
  • Network Setup (ตั้งค่าฝั่ง WLC):
    • Client Name: ใส่ชื่อ Client (เช่น WLC)
    • Client IP: ใส่หมายเลข IP ของเครื่อง WLC
    • Secret: ใส่รหัสผ่าน Shared Secret (เช่น radius123) -> กด Add
    • Server Type: ให้เลือกเป็น RADIUS
  • User Setup (สร้าง Username ให้คนเชื่อมต่อ):
    • Username: ใส่ชื่อผู้ใช้ (เช่น user1)
    • Password: ใส่รหัสผ่าน (เช่น pass123) -> กด Add

⚙️ Task 2: การตั้งค่า WLC-PT (คลิกที่ตัวอุปกรณ์ WLC-PT -> แท็บ Config)

  1. การตั้งค่า IP พื้นฐาน (Management):
    • ดูที่เมนูซ้ายมือ ภายใต้หัวข้อ INTERFACE -> เลือก Management
    • ใส่ IPv4 Address, Subnet Mask, Default Gateway, DNS Server ของตัว WLC ตามโจทย์กำหนด
  2. การตั้งค่าแจก IP (DHCP):
    • ดูที่เมนูซ้ายมือ ภายใต้หัวข้อ GLOBAL -> เลือก DHCP
    • ใส่ Pool Name, Default Gateway, DNS Server, Start IP Address และ Subnet Mask
    • กดปุ่ม Save
  3. การสร้างเครือข่าย Wi-Fi (Wireless LANs):
    • ดูที่เมนูซ้ายมือ ภายใต้หัวข้อ GLOBAL -> เลือก Wireless LANs
    • ใส่ Name และ SSID (เช่น staff-XX)
    • หัวข้อ Authentication เลือก WPA2 (สำหรับการเชื่อมต่อแบบ Enterprise/802.1x)
    • ภายใต้ RADIUS Server Settings ให้ใส่ IP Address ของ Server และ Shared Secret ให้ตรงกับที่ตั้งไว้ในหน้า AAA
    • กดปุ่ม Save
  4. การจัดกลุ่มการปล่อย SSID (AP Groups):
    • ดูที่เมนูซ้ายมือ ภายใต้หัวข้อ GLOBAL -> เลือก AP Groups
    • ใส่ชื่อกลุ่มในช่อง Name ด้านบน
    • ในกล่อง Wireless LANs: เลือก SSID ที่ต้องการให้กลุ่มนี้ปล่อย
    • ในกล่อง Access Points: เลือก AP ที่ต้องการให้อยู่ในกลุ่มนี้
    • กดปุ่ม Save
